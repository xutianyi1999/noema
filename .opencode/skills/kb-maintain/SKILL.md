# Noema 内容库维护

先阅读 `purpose.md` 和 `schema.md`。只在当前内容库的暂存项目中工作。

- 将发生变更或被删除的文本资料与受影响的 `wiki/` 节点重新对齐。
- 清理失效的来源引用和关系，但保留其他资料共同贡献的共享节点。
- 检查重复概念、相互冲突的声明、孤立节点和过期的生成产物。
- 保持原始资料不可变。使用上游 graphify Skill/CLI；不要创造内部知识库 MCP 工具。
- 将有歧义的修复放到 `reviews/`，并保留证据路径。
